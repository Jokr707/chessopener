# ChessOpener website

The website of ChessOpener, an iPhone and iPad app for learning chess openings:
https://jokr707.github.io/chessopener/

- `index.html`: support and contact
- `privacy.html`: privacy policy
- `licences.html`: licences of the components in the app

`source/stockfish.js-10.0.2-source.tar.gz` is the complete source code of the Stockfish build included in the
app (stockfish.js 10.0.2, commit e105072 of https://github.com/niklasf/stockfish.js), free software under the
GNU General Public License, version 3.
